# 问题四建模方案：历史能力分解与条件前沿预测

> 阶段：方案已执行；实际结果和相应收紧见文末第 8 节及独立结果报告。本方案依据正式可见题面和实际附件字段，不采用旧方案中的预设数值。

## 1. 目标与结论边界

用附件 C 定义开源模型的多维能力，量化历史变化中“规模变化”与“控制规模后的时间残差”，并在算力增长放缓的条件情景下预测 12/24 个月前沿。另用 C5/C6 检查前三问 Loss 与 Benchmark 的映射。

排行榜是观察性数据，时间、模型规模、训练数据、架构、后训练、评测版本与提交选择共同变化。下文的“非规模项”只能解释为**条件时间残差**，不能直接称为技术进步的因果效应。若早晚时段没有相近规模模型，贡献分解降级为描述，不强行估计百分比。

## 3. 样本、开放性与能力度量

1. 主时间轴用 C1 **提交日期**；仅在成功连接的子样本中用发布日期复核。重复提交按模型版本、评测哈希和日期去重；同一基础模型的微调版本归为同一家族。
2. 主口径是**权重可获得且许可证明确允许研究使用与复现**的文本模型。分别保存开放权重证据、许可证类别与核验状态；未知值不进入严格口径。另报“开放权重但许可限制较多”的宽口径，不能把它与严格开源混同。预审时 C2-Yes 与 Apache-2.0/MIT 等宽松许可交集为 239 行，其中 pretrained 42 行；正式建模前须按版本、家族重新审计。
3. `pretrained`、`continuously_pretrained`、`chat/finetuned` 分层；合并模型、多模态和类型不明者不进入主分解。参数量 ≤0 设缺失。C4 算力和数据量须核对单位、来源与 `Confidence`；`Speculative` 不进入主拟合。
4. 主能力指标为六任务百分制得分的等权均值：

   \[
   Y_i=\frac{1}{6}\sum_{k=1}^{6}S_{ik},\qquad
   k\in\{\mathrm{IFEval,BBH,MATH5,GPQA,MUSR,MMLU\!\mbox{-}\!PRO}\}.
   \]

   回代 C1 `Average ⬆️`。同时给出六任务各自结果、任务内标准化等权与逐一删任务敏感性；标准化参数仅由训练时间窗估计，避免未来信息泄漏。
5. **C8 必做 BBH 叶子任务宏平均。** 从 JSON `results` 取 `leaderboard_bbh_*` 叶子任务的同一 `acc_norm,none` 指标，排除 `leaderboard` 和 `leaderboard_bbh` 父级汇总，避免双计。只在相同任务集合、配置和版本下比较；94 个重复目录核对日期、revision/hash 与 task hash，预先指定选取规则，报告换用另一份的敏感性。与 C1 BBH 逐模型回代，列出覆盖率、偏差和不一致原因。

## 4. 规模与非规模变化的条件分解

**主模型：参数规模。** 在严格开放、同评测协议、同模型类型样本内，对六任务分别拟合有界得分模型：

\[
\operatorname{logit}\!\left(\frac{S_{ik}+\epsilon}{100+2\epsilon}\right)
=a_k+f_k(\log N_i)+g_k(t_i)+u_{\mathrm{family}(i)}+e_{ik}.
\]

$f_k$ 为低自由度、正则化的规模函数，$g_k$ 为低自由度时间项；与更简单的线性基线比较，按整家族和未来时段留出选复杂度。$\epsilon$ 仅处理 0/100 边界并做敏感性。若有效家族、时间块或早晚规模重叠不足，不估计时间残差。主模型估计的是**参数量规模贡献**，不是完整训练算力贡献。

**增强模型：训练算力或数据量。** C4 成功连接后，分别以 $\log C_{\rm train}$ 或 $\log D$ 替代 $\log N$ 建子样本模型，比较同样本结果。由于训练算力与 $N,D$ 强相关，不在同一回归中把三项系数解释为三个独立因果贡献。算力连接不足时明确放弃算力贡献百分比。

无论跨表连接能否成功，C4 均须单独审计其 `Training compute (FLOP)`、`Training dataset size (total)` 与 `Open model weights?` 的缺失、单位、可信度及按发布日期的变化；这可描述开源语言模型资源趋势，**不能在未连接 Benchmark 的情况下推断资源对能力的贡献**。

早晚时段固定为可比数据内的两个预设时间窗，限制在两期共同 $\log N$ 支持区间，并对家族重复提交做权重/去重。令 $M(R,t)$ 是把规模分布 $R$ 和时间 $t$ 输入拟合模型后的平均预测得分，则两因素 Shapley 分解为

\[
\phi_R=\tfrac12\{M(R_1,t_0)-M(R_0,t_0)+M(R_1,t_1)-M(R_0,t_1)\},
\]
\[
\phi_t=\tfrac12\{M(R_0,t_1)-M(R_0,t_0)+M(R_1,t_1)-M(R_1,t_0)\}.
\]

$\phi_R+\phi_t$ 等于模型预测变化；另报告实测变化和未解释残差。仅当总变化为正且区间远离零时报告占比，否则只报带符号的分数点。$\phi_t$ 仍可能包含遗漏的算力、数据、后训练与评测选择效应，不能写成“纯技术因果份额”。区间按基础模型家族重抽样，并做开放性、日期、类型和任务权重敏感性。

## 5. 前沿边界与 12/24 个月条件情景

1. 每个模型类型内同时报告**观测最高分**和预设高分位（例如条件 90% 分位），记录各月/季度模型数与独立家族数。最高分受提交量影响；高分位不是绝对物理上界。六任务前沿与综合前沿分开。
2. 比较简单时间趋势、含规模的惩罚高分位模型和无新增时间趋势基线。得分预测限于 0–100；用按时间滚动、整家族留出的 1–3 个月短期回测评估误差与区间覆盖。由于可比时间窗不足 12 个月，**不得宣称 12/24 个月外推已通过同长度回测**。
3. 由训练窗内可核验的规模增长率构造“延续、减半、停滞”情景；C4 算力连接不足时情景变量是参数量增长，不称为训练算力放缓。未来分数是规模与时间残差情景的条件预测；区间覆盖家族抽样、模型选择和情景差异，不只报回归标准误。
4. 主预测起点固定为最后一个同协议 C1 日期 **2025-03-13**，12/24 个月终点为 2026-03-13 / 2027-03-13。若需回答 2026 年竞赛时点之后的 12/24 个月，先补充可比新评测；否则只能给跨越未观测时间段的更宽情景区间，不能称为“当前实测前沿预测”。

## 6. Loss–Benchmark 桥接与前三问衔接

C6 高可比仅 7 个 Pythia 模型，平均分约 5.07–6.06；主桥接只在其 Loss/得分支持域内，比较单调的低复杂度映射与常数基线，逐模型留一并报告误差和区间。七条同属一个家族，留一不是跨家族验证。68 条中等可比记录混有不同验证集、训练 Loss 和验证 Loss；只能分来源或同源内差分做探索，不能与高可比组直接合并成统一绝对标尺。

若桥接方向、留一误差或支持域不支持有效预测，应明确写：**前三问 Loss 到排行榜前沿能力的数值映射尚未识别**。尤其不能把问题三在 B1/B6 支持域饱和后的高预算 Loss 直接翻译为未来开放模型分数。仍须完整报告桥接尝试、可比性等级和映射误差。

## 7. 验证门槛与交付顺序

- 输出“编号→文件→行数→字段→来源等级”数据合同与逐步样本流失表；C1/C3 重复、C1/C4 连接、开源/许可、类型、时间、算力、C8 JSON 均单列。连接表留痕，失败不得猜测补值。
- C8 逐任务聚合与 C1 BBH 回代；检查父子任务双计、版本不一致及缺失任务。
- 分解要求共同规模支持、家族留出和时间留出；不满足时降为描述性结果，不强行输出贡献比例。
- 桥接按高/中可比分列方向、误差、支持区间和越界比例；不得把跨验证集 Loss 当统一标尺。
- 预测明确区分短期可回测区间与 12/24 个月未验证外推；预测起点之后的 C4 数据不得泄漏到历史回测。

## 8. 执行后的识别收紧

- 主模型采用六任务等权均分的 logit-Ridge；六个单任务另做同样的未来时段留出。复杂度通过训练期按家族分组的交叉验证选择。未增加高自由度非线性项，因为样本和时间覆盖不足以稳定识别。
- 严格开放预训练的晚期样本只有 5 个，共同规模支持不能支撑贡献分解。严格开放后训练通过基本规模重叠门槛，但含时间模型的未来时段 RMSE 高于仅规模模型，且家族 Bootstrap 的总变化区间跨零，所以其分解只作探索性展示，不报告贡献比例。
- C4 的通过规则连接得到的训练算力子样本有选择性；仅报告与能力的观察性关联，不把它写作总体算力因果贡献。连接记录仍须论文作者复核。
- C6 高可比的 7 个 Pythia 点做留一单调回归，其误差未优于常数基线。因此前三问 Loss 与第四问前沿的数值桥接未成立。
- 观测月度高分位参数量趋势为负，且时间项没有通过未来时段验证；12/24 个月无同长度同协议回测。原计划的“延续／减半／停滞”正增长路径没有数据依据，正式执行不输出未来具体得分，只保存未识别审计。

第二轮自检进一步明确：许可证符合预设集合但权重状态为 `No` 的记录须与权重状态缺失分开；Epoch 元数据发布日期与排行榜提交日不等价，且部分日期晚于提交日，不作为后训练衍生模型的真实发布日期。Ridge 强度按家族均衡交叉验证选择；分解另用共同参数量支持区间重拟合作敏感性分析。具体修改和数值见 `验证验收/SELF_AUDIT_PROBLEM4.md`。

第三轮执行增加 C1/C4 的逐条来源证据队列、2024-07 至 2025-03 的逐月短期留出支持审计，以及对主要家族标签的删一影响排序。证据队列仍待人工核实；短期回测只有支持筛选通过的月份可作描述，不能取代 12/24 个月同协议验证。
