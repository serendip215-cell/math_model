# 问题一方法总览：从 0 到 1

本文档整理问题一从数据准备到最终结论的完整方法链，所有数字均为真实运行结果，
对应代码与产物路径见文末索引。写作用途：论文「模型建立与求解」章节的骨架素材。

## 方法链（一句话版）

> 数据风险隔离 → A1 单标尺 22 指标质量评分（方向统一 + 适中型单峰 + CRITIC + Huber）
> → 组间冲突标注 → ILR 成分数据二次响应面（三集分工防泄漏）→ 实测质心法推荐配比
> （Bootstrap 区间）→ 质量外部效度锚定 + inferred 域 Q 代理补全（质量增强翻转采纳）
> → 逐域效应标度律外推 + 置信衰减（大尺度方向反转减弱至接近零）
> → 三项稳健性闭环（交叉拟合 Q / 冲突降权消解 / 质心正则化路径）→ 有效性边界声明。

## 第 0 步之前：题目理解与四条设计原则

**问题一要什么**（依据附件 A 的绑定关系与《数据说明》可见层整理，非题面原文引用）：

- **输入**：A1–A3（质量信号抽样与 arxiv/github 扩展）、A4–A11（512+256 组配方与实测
  Loss，1M/60M/1B 为实测、10B/70B 为估计）、A16（17 域映射表）；
- **任务**：① 对 22 维质量指标构建域级质量评分 Q，并消解指标间冲突；
  ② 建立 17 域配比 → 13 域 Loss 的响应面模型；③ 给出推荐配比并检验其跨尺度有效性；
- **输出**：域级 Q 与冲突消解方案、响应面模型、推荐配比（含不确定性区间）。

**贯穿全程的四条设计原则**（后续每一步的方法选择都能追溯到其中一条）：

1. **三集分工，绝不泄漏**：A4–A5 只做训练选型，A6–A7 只做独立检验，A8–A11 跨尺度
   检验，A12–A15（est）只做压力测试——模型选择、超参数、采纳决策全部只依据训练集
   内部交叉验证；
2. **稳健优先**：Huber 位置代替均值、实测质心代替响应面边界解、Bootstrap 区间代替
   点估计、域级用中位数汇总；
3. **每个结论配一个闭环**：Q 有外部效度锚点 + 交叉拟合归因检验，配比模型有逐域消融，
   冲突有敏感性分析 + 消解闭环，推荐配比有正则化路径实证，跨尺度有标度律外推；
4. **如实报告边界**：不显著就报告不显著（全样本 Q 锚点 r=0.062 不显著，覆盖>30% 才
   有 r=0.399），est 尺度永远标注"估计量"，未能验证的写入局限声明。

## 第 0 步：数据风险隔离与准备

**问题**：题面 PDF 混有隐藏内容；原始附件为分片压缩大文件。

1. **PDF 注入审计**：扫描题面 PDF，发现 96 条近白色 5pt 隐藏文本 span，全部隔离；
   建模代码路径常量写死为 `F题_清洗后`，禁止读取原始附件（real_attachments）。
2. **大文件恢复**：`restore_large_files.ps1` 合并 5 个分片原文件，SHA256 逐一校验通过。
3. **数据修复**：解压 `.xz`、修复损坏 JSON 行、`#Params=-1` 统一转缺失。
4. **口径文件**：题面数据说明过滤出可见层（`F题_清洗后/题面数据说明/数据说明_可见层.md`），
   作为建模唯一文字依据。

方法论意义：赛题数据内嵌干扰信息，第一步即用目录隔离 + 路径常量焊死在流程外。

## 第 1 步：质量评分 Q（A1/A2/A3，272,505 条 × 22 指标）

**输入**：A1（7 域样本）、A2（arxiv 扩展）、A3（github 扩展）JSONL。流式读取，
无效 JSON 0 行，跨文件重复 ID 11,419 单独汇总不删除。

四层处理：

1. **字段形状归一**：二分类 logits → softmax 第二类概率；六级评分 logits → softmax
   期望 ×(1/5)；`qurater` 四分量 → expit 后均值；其余取 finite 值。
2. **方向统一（A1 是唯一标尺）**：1%–99% 分位裁剪到 [0,1]；14 个收益型正向、5 个成本型
   反向（如广告倾向 ad_en）；3 个长度类指标（词数/句数/平均词长）做**适中型单峰处理**：
   Gaussian 衰减 `exp(-0.5((x-center)/spread)²)`，center=A1 中位数，spread=1.5×IQR。
   该处理是我们 Q 排序与部分公开口径反转的根源：book/c4 为长文档域，收益型处理会加分，
   适中型处理按"过长冗余"扣分。
3. **权重**：22 指标按语义分 4 组（知识价值 6 / 语言表达 3 / 洁净规范 8 / 结构丰富 5），
   组内 CRITIC 权重（std × 独立性），组间等权。
4. **稳健汇总**：Huber 位置估计（δ=0.15），残差大的组自动降权；A2/A3 复用 A1 标尺
   不重估，保证跨数据集可比。

**结果**：Q 均值 0.6047（σ=0.1007）；arxiv 0.782 > stackexchange 0.715 >
commoncrawl 0.707 > **c4 0.685** > wikipedia 0.622 > github 0.577 > book 0.569；
A1 与 A2/A3 同域差仅 -0.005 / -0.001，标尺跨集稳定。

## 第 2 步：冲突分析（质量的不确定性标注）

**定义**：同一文本上语义组意见不一致——组间差 `K_i = Σ_{g<h} w_g w_h |G_ig − G_ih|`，
阈值取 A1 的 K 分布 90% 分位（0.2714），A2/A3 直接套用。

**产出**：全样本冲突率 10%（阈值定义决定）；分域 c4 最高 28.76%，主导冲突对为
"洁净规范高—语言表达低"（48.78%，终止标点规范 vs professionality）。
敏感性验证：统一阈值是唯一跨域可比方案；指标变异系数与冲突率无关（r=-0.041）——
冲突根因是组间意见分歧，不是指标噪声。

## 第 3 步：配比 → Loss 响应面（17 域投入 → 13 域 Loss）

**约束处理**：17 域配比总和=1（单纯形数据），直接回归共线性爆炸 →
**ILR 变换**（eps=1e-6 补零，Helmert 正交基，降到 16 维无约束坐标）。

**三集分工（贯穿全程的纪律）**：

- A4–A5（512+256 配方）：训练 + 五折交叉验证选型；
- A6–A7（test_1m）：独立检验，不参与任何选型；
- A8–A11（60M/1B）：跨尺度外推检验；
- A12–A15（est_10b/70b）：估计量，只做压力测试，绝不参与拟合。

**选型结果**（目标按 13 域 z-score 标准化）：

| 模型 | 五折 CV MSE | 判定 |
| --- | --- | --- |
| linear_ilr_ridge | 0.1944 | 基线 |
| quadratic_ilr_ridge | 0.1471（-24.3%） | 选中 |
| quadratic + 质量特征 | 0.1360（-7.6%） | 不采纳：独立检验 RMSE 反升 1.1%，双门槛（内部 CV 且独立检验均改善 ≥2%）不通过 |

**主结果**：test_1m macro RMSE 0.2319，Spearman 0.6659；跨尺度 Spearman
0.626（60M）→ 0.527（1B）→ -0.59 / -0.67（est_10b/70b，方向反转，见第 8 步解决）。

## 第 4 步：推荐配比

- 响应面解析解：约束内多起点优化，10 个分量推到边界 → 弃用；
- **主推荐**：按 A4–A5 实测（非预测）标准化 Loss 排序，取最优前 10%（52 配方）的
  17 维质心，300 次 Bootstrap 95% CI。总和=1.0，最大单域 pile_cc 0.1513
  （CI [0.107, 0.202]），前五域 pile_cc / wikipedia_en / pubmed_central /
  stackexchange / uspto_backgrounds 合计 53.2%。

## 第 5 步：验证迭代（4 处自查修正）

| 原问题 | 修正 |
| --- | --- |
| macro RMSE 与 Spearman 口径不一致 | 统一为"先逐配比平均 13 域 Loss 再算误差" |

## 第 6 步：增强验证（problem1_enhancement.py，6 模块）

1. **质量外部效度锚点**：配方加权质量 = Σ(pᵢ×Qᵢ) 与实测 Loss 的相关——
   覆盖>30% 的配方 r=0.357（p<2e-13），独立检验集 r=0.179；但全样本相关不显著，且覆盖率与加权和仍有混杂，因此只作弱外部锚点，不单独证明 Q 有效。
2. **真实 R² 与 Δφ 差分相关**：R² = 1 − SSE/SST（等价于 MSE 除以 ddof=0 的均方离差）。
   train 0.623 / test_1m **0.302**（test 均方离差 0.0771）；60M 及以上去均值 R² 近零或为负
   （1B macro Loss 方差仅 0.0027，1M 效应幅度在绝对 MSE 意义下不匹配）——大尺度只报
   去均值 RMSE（0.216/0.154）与 Spearman（0.626/0.527），不报 R²。
   早期"检验 R²=0.946"系 `1−RMSE²` 公式误用于非单位方差目标，已更正（corrected_r2.csv）。
   Δφ 差分相关量级小（0.02–0.29），作辅助指标。
3. **域级消融**：github（+7.59%）、arxiv（+5.27%）为刚性域；stackexchange（-6.01%）、
   wikipedia_en（-1.43%）在训练集有过拟合迹象；pile_cc 推荐占比最高但消融贡献弱
   （+0.66%）——质心法已知特性（Loss 方差小的域自然聚集于最优配方），论文需显性解释。
4. **跨尺度推荐质心**：pile_cc 占比 1M 10% → 60M 12.8% → 1B 21.1%，
   高质量域权重随算力上升——直接扣"算力约束"题眼。
5. **Δφ 差分相关**：局部效应补充视角（量级小，作辅助指标）。
6. **冲突敏感性**：见第 2 步。

## 第 7 步：11 个 inferred 域 Q 补全（inferred_quality_proxy.py）

原质量增强不采纳的根因是 11 个域没有 Q。两种代理：

- **方法 A（数据驱动）**：train_1m 上各域配比对 macro Loss 的偏相关
  （控制其余 16 域），负偏相关 → 高隐含质量；
- **方法 B（语义映射）**：学术域→arxiv(0.782)、法务→book、社区文本→github 等
  A16 语义线索；
- 两法平均补全 17 域 Q。

**结果与边界**：该探索性代理在简化版模型上改善 test_1m 预测，但 11 个 inferred 值由训练 Loss 反演并混合人工语义映射，不能视为 A1 质量评分的独立外部信息。它只作为“监督式低维代理是否有预测价值”的敏感性分析。最终主模型仍采用 A16 可核验的 6/17 域映射结论：Q 未达到独立检验双门槛，不进入最终预测器。

## 第 8 步：配比效应标度律 + 置信衰减（scaling_effect_decay.py）

**建模**：每个实测尺度（1m/60m/1B）分别对 13 个 Loss 域拟合线性 ILR 系数 →
每个 ILR 坐标拟合系数随 log10(N) 的趋势 → 留一尺度 CV 选斜率收缩因子 λ*=0.75 →
外推到 10B/70B（幅值 3 倍安全截断）。

**两个新参数**：

- **κ=0.15**（13 域中位）：效应幅值衰减指数；dm_mathematics 最快（0.45），
  wikipedia_en / freelaw 几乎不衰减（0.01–0.05）——"配比答案本身随规模变化"的定量证据。
- **置信衰减**：N>1B 后配比项按 w(N)=(N/1e9)^(-κ) 向尺度基线收缩
  （w(10b)=0.71，w(70b)=0.53）。

**效果**（est 尺度仅作外部检验，零参与拟合）：

| 变体 | est_10b Spearman | est_70b Spearman | est RMSE |
| --- | --- | --- | --- |
| 不外推（frozen_1B） | -0.084 | -0.098 | 0.165 / 0.173 |
| 趋势外推（extrap_trend） | +0.021 | +0.071 | 0.179 / 0.203 |
| 置信衰减（decay_fusion） | -0.084 | -0.098 | 0.137 / 0.133 |

反转幅度从主模型直推的 −0.59/−0.67 大幅减弱至 ±0.1 以内（extrap_trend 转正 +0.02/+0.07，
decay_fusion 仍为 −0.08/−0.10）；绝对误差向保守基线收敛，但 est 排序精度无实用价值。
趋势外推在实测尺度同样更优
（train_1m Spearman 0.117→0.448，test_1m -0.013→0.368）——三尺度趋势对每尺度系数有去噪作用。

**结论表述**：1M–1B 实测范围内二次响应面排序相关保持为正但随尺度递减
（Spearman 0.80→0.63→0.53），只能称"仍有一定排序能力"，不能称"可靠"；
10B/70B 的趋势外推相关转为微弱正值（0.02–0.07），置信衰减变体仍为微弱负值；两者均无实用排序精度，不能称为“反转已经消除”；
且 est 尺度上纯规模基线的 RMSE（0.099/0.110）低于所有含配比项的变体——这恰好
支持"大尺度应向基线收缩"的置信衰减主张，而非支持配比外推的绝对精度。
精确配比需问题二的完整标度律框架。

## 第 9 步：三项稳健性升级（refinement_three.py）

针对方法链三个最可能被质疑的环节，各补一项闭环验证。

### 9.1 Loss-informed Q 代理的嵌套折外评估

**质疑**：第 7 步的 inferred 域 Q 由 train_1m 的偏相关导出，而质量增强消融也在
train_1m 上评估——Q 的构造与模型评估共享同一份数据，存在归因污染风险
（注意：非经典数据泄露，test_1m 评估集本身干净，风险在于高估训练期贡献）。

**修正**：使用外层五折。每一折只在其余四折上估计缺失域的偏相关代理、拟合预测器，再对留出折预测；不再把五个训练子集的偏相关简单平均后回用于全部训练样本。由于成分占比共线，偏相关残差化改用带截距 Ridge。人工语义 Q 不进入本项检验。

**结果**：外层折外 baseline RMSE/Spearman 为 0.2857/0.5846，加入 Loss-informed 代理后为 0.2506/0.6812；独立 test_1m 为 0.2368/0.6624 → 0.2078/0.7339。结果说明该监督式代理有预测增量，但其 inferred 分量来自训练 Loss，所以不把它解释为独立质量效应，`adopted_as_quality_score=False`。

### 9.2 冲突降权消解闭环（验证"标注即处理"）

**质疑**：第 2 步只标注了冲突（K_i）未消解；若对高冲突样本降权会改变结论，
则质量评分对冲突定义敏感。

**修正**：在 A1 样本上对比三种域级汇总——原始中位数 / 冲突降权加权中位数
（w=1−K）/ 惩罚式（Q×(1−0.5K)），考察域排序稳定性。
惩罚式仅作敏感性变体：Huber 汇总已在组内降权一次，Q×(1−λK) 属双重惩罚，
且会把"意见分歧"与"质量低"混为一谈。

**结果**：三种口径的域排序 Spearman 全部为 1.0000（排序完全一致）；
逐域数值变化降权式最大 1.10%、惩罚式最大 11.65%。

**结论**：冲突标注天然闭环——降权消解不改变任何域级结论，Q 对冲突
定义稳健；同时实证了"不用惩罚式做主 Q"的设计选择（惩罚式会扭曲数值
10 倍以上而同样不改变排序，纯增噪声）。

### 9.3 推荐配比正则化路径（质心法的实证辩护）

**质疑**：第 4 步弃用响应面边界解改用实测质心，是经验选择；若模型预测的
"更优"边界解真实存在，质心法代价多大？

**修正**：信任域正则化路径扫描——求解
`min_z pred_quad(z) + λ·‖z−z_centroid‖²`（λ 从 0 到 ∞，L-BFGS-B 多起点），
追踪每个 λ 下解到质心的距离、最大单域占比、活跃域数、预测 Loss，
以及**解的最近实测配方及其真实 Loss**。

**结果**（λ 路径表，完整数据见 regularization_path.csv）：

| λ | 到质心距离 | 最大占比 | 模型预测（标准化逆变换） | 最近实测配方真实 Loss |
| --- | --- | --- | --- | --- |
| 0（纯边界解） | 40.79 | 0.363 | 1.93 | 5.12 |
| 0.03 | 1.93 | 0.145 | 5.05 | 4.98 |
| 1.0 | 0.051 | 0.150 | 5.11 | 4.98 |
| ∞（=质心） | 0 | 0.151 | 5.11 | **4.98** |

**解读**（三层，缺一不可）：

1. λ=0 的边界解预测 Loss 1.93，但它离最近实测配方距离 33.9（ILR 单位）——
   该预测是对训练配方凸包外的**外推幻象**；其邻域最近实测配方真实 Loss 5.12，
   并不优于质心邻域；
2. λ≥0.03 解立即收敛到质心邻域（最大占比 0.363→0.145→0.151），响应面
   在质心附近本身平坦，"保守化"几乎不损失预测值；
3. 决定性证据：质心最近实测配方的**实测** Loss 4.98 优于边界解邻域的 5.12——
   质心法不仅防外推，而且在实测意义上更优。"保守性代价"（训练集最低预测
   − 质心预测 = −1.28σ）应解读为：预测意义上质心确实"贵"1.28σ，
   但该差值全部来自外推区的不可信预测，实测邻域对照为 −0.14（原始单位，
≈−0.43σ；质心更优）。

**结论**：推荐配比采用实测质心从"经验规避"升级为"路径扫描 + 实测邻域
验证"的实证结论，第 4 步的方法选择获得闭环证据。

## 剩余局限（论文中主动声明）

- est_10b/70b 的 Loss 是题目估计量，只能做外部一致性检验，不能宣称验证真实大尺度行为；
- 推荐配比未经真实训练验证（算力约束）；

  此局限仅影响冲突成因的语义解释深度）；
- inferred 域目前只有 Loss-informed 代理，不能替代独立质量测量；若要把 17 域 Q 正式并入主模型，需对相应域文本运行同一质量评分器或取得新的外部标注。
